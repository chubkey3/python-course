What does this code print?

 [1, 2, 3] [2, 4, 6] [1, 2, 3, 2, 4, 6] 6

x gets a copy of each item. x = x * 2 changes x only; the list is never touched, so it still prints [1, 2, 3].

To really double every item, loop over the indices and assign into the list:

for i in range(len(nums)):
    nums[i] = nums[i] * 2
