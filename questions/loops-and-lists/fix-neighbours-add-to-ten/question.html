The program in the editor is supposed to count how many pairs of neighbours, nums[i] and nums[i + 1], add up to $10$. It has 2 bugs. Run it, read the errors, and fix them.

Input: the first line contains an integer $N$ ($1 \le N \le 1000$), the length of the list. Each of the next $N$ lines contains one integer of the list (between $-1000$ and $1000$).

Output: print the number of neighbour pairs that add up to $10$.

Sample input 1

5 3 7 3 5 5

Sample output 1

3

$3 + 7$, $7 + 3$ and $5 + 5$ add up to $10$, but $3 + 5$ doesn't. The answer is $3$.

Sample input 2

1 10

Sample output 2

0

A single number has no neighbour, so the answer is $0$.

Model solution

  • Bug 1: count never gets a starting value, so count = count + 1 fails with NameError. Add count = 0 before the loop.
  • Bug 2: on the last pass, i is n - 1 and nums[i + 1] is nums[n], which doesn't exist (IndexError: list index out of range). The last pair starts at index n - 2, so loop over range(n - 1).
