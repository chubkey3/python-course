Choose the code that goes in each blank so the program does what it says.

(a) Print the list backwards: 9, then 3, then 7.

Blank __1__: -1 0 1 len(nums)   Blank __2__: -1 1 0 -2

(b) Print the index of the largest value, then the value. It should print 2 9.

Blank __1__: best i i - 1 0   Blank __2__: i nums[i] best i + 1

(c) Count how many items are bigger than the item before them. It should print 2.

Blank __1__: 1 0 2 -1   Blank __2__: i - 1 i + 1 i 0

(a)

nums = [7, 3, 9]
for i in range(len(nums) - 1, -1, -1):
    print(nums[i])

Start at the last index (2) and step -1. The stop value is not included, so to reach index 0 the stop must be -1. A stop of 0 would print only 9 3.

(b)

nums = [6, 2, 9, 4]
best = 0    # index of the largest value so far
for i in range(1, len(nums)):
    if nums[i] > nums[best]:
        best = i
print(best, nums[best])

best stores an index, so compare against nums[best] and store the new index i. The largest value is always nums[best], so no separate variable for it is needed.

(c)

nums = [9, 5, 3, 4, 8]
count = 0
for i in range(1, len(nums)):
    if nums[i] > nums[i - 1]:
        count = count + 1
print(count)

The item before index i is at i - 1. Index 0 has nothing before it, so start at 1. Starting at 0 would compare nums[0] with nums[-1] (the last item) and wrongly print 3. Using i + 1 would read past the end: IndexError.
