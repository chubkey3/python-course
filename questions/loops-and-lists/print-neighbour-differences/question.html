What does this code print?

Each value is printed on its own line; the choices show them separated by spaces.

 3 -6 7 -3 6 -7 -4 3 -6 7 1 1 1 IndexError

i goes 1, 2, 3. Each time it prints an item minus the item before it:

  • i = 1: 8 - 5 = 3
  • i = 2: 2 - 8 = -6
  • i = 3: 9 - 2 = 7

Starting at 1 matters: at i = 0, nums[i - 1] would be nums[-1], the last item.
