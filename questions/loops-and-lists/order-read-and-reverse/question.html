The input is a number $N$, then $N$ numbers, one per line. Build a program that reads the numbers into a list and then prints them in reverse order, one per line.

Drag the lines into the box in the right order. Not every line is used.

Indentation matters, just like in Python, and you control it: drag a line to the right to indent it inside the loop above it, or to the left to move it back out. A line in the wrong place or with the wrong indentation is marked wrong.

 n = int(input()) nums = [] for i in range(n): nums.append(int(input())) for i in range(n - 1, -1, -1): print(nums[i]) for i in range(n - 1, 0, -1): for i in range(n, 0, -1): print(nums) 
n = int(input())
nums = []
for i in range(n):
    nums.append(int(input()))
for i in range(n - 1, -1, -1):
    print(nums[i])

Indentation decides what is inside each loop: nums.append(...) is indented under the first loop, so it runs once per number read, and print(nums[i]) is indented under the second loop, so it runs once per index.

First build the list front to back. Then walk the indices backwards from the last index, n - 1, down to 0. The stop value is not included, so it must be -1.

  • range(n - 1, 0, -1) stops before index 0, so the first number is never printed.
  • range(n, 0, -1) starts at index n, which doesn't exist (IndexError).
  • print(nums) prints the whole list in brackets, on one line.
