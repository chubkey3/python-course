You are given a list of integers. Using a while loop, print the numbers in order until you reach the first negative number. Don't print that number or anything after it. Finally, print the word done.

Input: the first line contains an integer $N$ ($1 \le N \le 1000$), the length of the list. Each of the next $N$ lines contains one integer of the list (between $-1000$ and $1000$).

Output: the numbers before the first negative number, one per line, then done.

Sample input 1

6 4 9 0 -3 5 -1

Sample output 1

4
9
0
done

$-3$ is the first negative number, so only $4$, $9$ and $0$ are printed. ($0$ is not negative.)

Sample input 2

3 2 5 8

Sample output 2

2
5
8
done

There are no negative numbers, so every number is printed.

Model solution

Walk through the list with an index: start at i = 0, keep going while i < n, and move on with i += 1. When nums[i] < 0, break ends the loop before that number is printed. The i < n check stops the loop at the end of the list when there is no negative number. print("done") is after the loop, so it always runs.
