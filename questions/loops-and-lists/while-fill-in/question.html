for i in range(len(nums)):

Blank __1__: 0 1 -1 len(nums)
Blank __2__: < <= > ==
Blank __3__: += 1 -= 1 = 1 + 1 

nums = [6, 1, 9]
i = 0
while i < len(nums):
    print(nums[i])
    i += 1

A while loop over a list needs three things: start the index at 0, keep going while i < len(nums), and move to the next index with i += 1.

  • <= would also try nums[3], which doesn't exist (IndexError).
  • -= 1 would go backwards to nums[-1], nums[-2], ... and then crash.
  • = 1 would set i back to 1 every time, and + 1 calculates a number without saving it: both loop forever.
