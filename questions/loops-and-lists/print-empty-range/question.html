What does this code print?

Each value is printed on its own line; the choices show them separated by spaces.

 done hi hi hi done hi hi hi hi done (nothing)

Without a step, range counts up by 1. range(5, 2) starts at 5, which is already past the stop value 2, so it is empty and the loop body never runs. Only done prints. (To count down you would need range(5, 2, -1).)
