You are given a list of integers nums. Count how many positions i have nums[i] == i. Indices start at $0$, as in Python.

Input: the first line contains an integer $N$ ($1 \le N \le 1000$), the length of the list. Each of the next $N$ lines contains one integer of the list (between $-1000$ and $1000$).

Output: print the number of positions where the value equals its index.

Sample input 1

4
0
5
2
1

Sample output 1

2

nums[0] == 0 and nums[2] == 2, so the answer is $2$.

Sample input 2

4
3
1
2
3

Sample output 2

3

Indices $1$, $2$, and $3$ match, so the answer is $3$.

Write your solution in main.py in the workspace. Read input with input() and print your answer with print(). Do not print any extra text such as prompts.

To test, open a terminal in VS Code and run python3 main.py < sample_input.txt (or run python3 main.py and type the input yourself). When you are ready, click Save & Grade below. Your code is run on the sample tests and on hidden tests.
