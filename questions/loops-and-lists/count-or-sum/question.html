Choose the line that goes in the blank for each task.

(a) Print how many even numbers there are: answer = answer + 1 answer = answer + nums[i] answer = answer + i answer = nums[i] answer = 1

(b) Print the sum of the even numbers: answer = answer + 1 answer = answer + nums[i] answer = answer + i answer = nums[i] answer = 1

The even numbers are 8 (index 1) and 6 (index 2).

  • Counting adds 1 each time: answer = answer + 1 prints 2.
  • Summing adds the item each time: answer = answer + nums[i] prints 14.

The other lines: answer = answer + i adds the indices (prints 3), answer = nums[i] keeps only the last even item (prints 6), and answer = 1 just sets it to 1.
