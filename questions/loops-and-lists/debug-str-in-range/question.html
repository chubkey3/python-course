This program crashes when you type 3 as the input:

Python shows this error:

Traceback (most recent call last):
  File "main.py", line 2, in <module>
    for i in range(n):
             ~~~~~^^^
TypeError: 'str' object cannot be interpreted as an integer

Which change fixes it?

 Change n = input() to n = int(input()) Change range(n) to range(len(n)) Change for i in range(n): to for i in n: Change range(n) to range(str(n)) Change print(i) to print(int(i))

str means string, which is text. input() always gives back text, even when you type 3: you get '3', not 3. range() needs a whole number (int), so Python complains it can't use a str as an integer.

Fix: convert as you read, n = int(input()). Then the program prints 0 1 2.
