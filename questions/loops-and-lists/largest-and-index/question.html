You are given a list of integers. Print the largest value, and then its index. If the largest value appears more than once, print the first index where it appears.

Try it without using max().

Input: the first line contains an integer $N$ ($1 \le N \le 1000$), the length of the list. Each of the next $N$ lines contains one integer of the list (between $-1000$ and $1000$).

Output: print the largest value on the first line and its index on the second line.

Sample input 1

5 3 9 2 9 4

Sample output 1

9
1

The largest value is $9$. It appears at index $1$ and index $3$, and the first one is $1$.

Sample input 2

3 -5 -2 -8

Sample output 2

-2
1

Every number is negative. The largest is $-2$, at index $1$.

Model solution

Keep just the index of the best item so far, best. Its value is always nums[best], so no second variable is needed. Start with best = 0 (the first item), not with the value 0, which would be wrong when every number is negative. Use >, not >=, so that a tie does not replace the first index.
