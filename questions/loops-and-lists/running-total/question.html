You are given a list of integers. After each number, print the running total: the sum of all the numbers so far.

Input: the first line contains an integer $N$ ($1 \le N \le 1000$), the length of the list. Each of the next $N$ lines contains one integer of the list (between $-1000$ and $1000$).

Output: print $N$ lines. Line $k$ is the sum of the first $k$ numbers.

Sample input 1

4 3 1 4 2

Sample output 1

3
4
8
10

The running totals are $3$, then $3 + 1 = 4$, then $4 + 4 = 8$, then $8 + 2 = 10$.

Model solution

Keep a rolling sum with total = total + nums[i], starting from total = 0 before the loop. The print goes inside the loop, so a total is printed after every number, not just at the end.
