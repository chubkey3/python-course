Read integers one at a time. Stop as soon as you read a $0$, and print the sum of the numbers that came before it.

Input: integers, one per line, each between $-1000$ and $1000$. There is always at least one $0$, and at most $1000$ numbers come before the first $0$. Anything after the first $0$ must be ignored.

Output: print the sum of the numbers before the first $0$.

Sample input 1

4 7 -2 0

Sample output 1

9

$4 + 7 + (-2) = 9$. Then the $0$ stops the loop.

Sample input 2

5 0 8

Sample output 2

5

Only $5$ comes before the $0$. The $8$ comes after it, so it is never added.

Model solution

Read the first number before the loop. The loop runs while number != 0: add the number to the rolling sum, then read the next number at the end of the loop body. When a $0$ is read, the condition is false and the loop ends, so nothing after the $0$ is ever read.
