You are given a list of integers. Print the sum of every number in the list that is even.

Careful: this means even values, not values at even indices. If the list has no even numbers, print $0$. Negative numbers can be even too (for example, $-4$).

Input: the first line contains an integer $N$ ($1 \le N \le 1000$), the length of the list. Each of the next $N$ lines contains one integer of the list (between $-10^6$ and $10^6$).

Output: print the sum of the even numbers.

Sample input 1

5
1
2
3
4
5

Sample output 1

6

The even numbers are $2$ and $4$, and $2 + 4 = 6$.

Sample input 2

4
3
4
7
8

Sample output 2

12

The even numbers are $4$ and $8$, so the answer is $12$. (Summing the values at even indices would give $3 + 7 = 10$, which is wrong.)

Write your solution in main.py in the workspace. Read input with input() and print your answer with print(). Do not print any extra text such as prompts.

To test, open a terminal in VS Code and run python3 main.py < sample_input.txt (or run python3 main.py and type the input yourself). When you are ready, click Save & Grade below. Your code is run on the sample tests and on hidden tests.
