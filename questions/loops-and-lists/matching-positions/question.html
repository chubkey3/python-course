You are given two lists a and b of the same length. Count how many positions i have a[i] == b[i].

Input: the first line contains an integer $N$ ($1 \le N \le 1000$), the length of both lists. The next $N$ lines contain the integers of list a, one per line. After that, the next $N$ lines contain the integers of list b, one per line.

Output: print the number of positions where the two lists match.

Sample input 1

4
1
2
3
4
1
5
3
0

Sample output 1

2

a = [1, 2, 3, 4] and b = [1, 5, 3, 0]. They match at index $0$ and index $2$, so the answer is $2$.

Write your solution in main.py in the workspace. Read input with input() and print your answer with print(). Do not print any extra text such as prompts.
