You are given a list of integers nums. Count the indices i where nums[i] > nums[i - 1], that is, how many items are bigger than the item just before them.

Input: the first line contains an integer $N$ ($1 \le N \le 1000$), the length of the list. Each of the next $N$ lines contains one integer of the list (between $-1000$ and $1000$).

Output: print the number of such indices.

Sample input 1

6 1 4 2 2 5 7

Sample output 1

3

$4 > 1$, $5 > 2$ and $7 > 5$, so the answer is $3$. The second $2$ is equal to the item before it, so it doesn't count.

Sample input 2

4 8 3 5 1

Sample output 2

1

Only $5 > 3$ counts, so the answer is $1$. Index $0$ has no item before it.

Model solution

The item before index i is at index i - 1. Index 0 has nothing before it, so the loop starts at 1: range(1, n). Starting at 0 would not crash, but it would compare nums[0] with nums[-1], the last item, and could count one extra.
