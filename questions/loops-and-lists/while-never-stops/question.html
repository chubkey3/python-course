Which of these loops never stops?

 
i = 0
while i < 3:
    print(i)
    i += 1
 
count = 5
while count >= 1:
    print(count)
    count -= 1
 
nums = [1, 3, 5, 8]
i = 0
while i < len(nums):
    if nums[i] == 5:
        break
    i += 1
 
numbers = [10, 60, 20]
i = 0
while i < len(numbers):
    if numbers[i] >= 50:
        continue
    print(numbers[i])
    i += 1

In the numbers loop, when i is 1, numbers[1] is 60. 60 >= 50 is true, so continue jumps straight back to the top of the loop, skipping i += 1. i stays 1 forever, and it checks 60 again and again.

Fix: make sure i still goes up before continue:

while i < len(numbers):
    if numbers[i] >= 50:
        i += 1
        continue
    print(numbers[i])
    i += 1
