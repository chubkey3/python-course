Count down from a starting number. Start at start, then keep subtracting step. Print every number that is greater than or equal to $0$. If the count lands exactly on $0$, print $0$ too.

Input: the first line contains the integer start ($0 \le$ start $\le 1000$). The second line contains the integer step ($1 \le$ step $\le 100$).

Output: print the numbers in the countdown, one per line.

Sample input 1

10
2

Sample output 1

10
8
6
4
2
0

The count lands on $0$, so $0$ is printed.

Sample input 2

10
3

Sample output 2

10
7
4
1

The next number after $1$ would be $-2$, which is below $0$, so the count stops at $1$.

Write your solution in main.py in the workspace. Read input with input() and print your answer with print(). Do not print any extra text such as prompts.

To test, open a terminal in VS Code and run python3 main.py < sample_input.txt (or run python3 main.py and type the input yourself). When you are ready, click Save & Grade below. Your code is run on the sample tests and on hidden tests.
